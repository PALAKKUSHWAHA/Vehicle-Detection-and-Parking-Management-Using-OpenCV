# Vehicle-Detection-and-Parking-Management-Using-OpenCV
This project leverages Python and OpenCV to detect and classify vehicles in real time—no heavy ML models required—making it ideal for smart‑parking and traffic‑monitoring applications. By processing live camera feeds or video files, it identifies moving objects, draws bounding boxes around vehicles, and categorizes them by size.

* **Objective**

  * Detect moving vehicles frame by frame
  * Classify each vehicle into categories (car, truck, bike)
  * Enable efficient smart‑parking management and traffic analysis

* **Tech Stack**

  * Python 3
  * OpenCV (background subtraction, contour detection, morphological operations)
  * NumPy
  * Jupyter Notebook or VS Code

* **How to Run**

  * Clone the repository and install dependencies:

    * `pip install opencv-python numpy`
  * Point the script at a video file or your webcam
  * Execute the main detection script (e.g. `python vehicle_detection.py`)

* **Project Outcome**

  * Real‑time detection with bounding boxes and timestamps
  * Basic size‑based classification accuracy suitable for parking/traffic systems
  * Exported result videos or images for further analysis

* **Applications**

  * Automated smart‑parking entry/exit logging
  * Traffic surveillance and flow monitoring
  * Vehicle‑type statistics for urban planning
